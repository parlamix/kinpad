# KinPad

KinPad is a small, file-first writing app for plain text and Markdown.

[Download KinPad](https://kinpad.org/download/) · [Release details](https://kinpad.org/releases/2026.9.1/) · [Support](SUPPORT.md) · [Security](SECURITY.md)

## Current release

KinPad 2026.9.1 is available for 64-bit Windows in English.

- **EXE:** recommended for most people
- **MSI:** for organizations

KinPad works offline after installation. The installer may need internet to add Microsoft WebView2.

The [official download page](https://kinpad.org/download/) is the authoritative source for installers, hashes, release notes, and verification information.

## What KinPad does

- Starts with a blank draft.
- Opens and saves ordinary `.txt` and `.md` files.
- Keeps a few documents open in simple tabs.
- Provides local recovery for unsaved work.
- Offers clear and deep focus themes.
- Uses no account, subscription, advertising, or telemetry.

## What KinPad is not

KinPad is not a cloud service, collaboration suite, rich document editor, AI assistant, or plugin platform. It does not include sync or automatic updates.
