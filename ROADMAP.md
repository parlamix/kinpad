# KinPad roadmap

KinPad stays focused on dependable, uncomplicated writing with ordinary files.

## Current

- 64-bit Windows
- English interface and UTF-8 text
- EXE and MSI distribution
- Plain text and Markdown files
- Local recovery for unsaved work

## Considering

- Focused writing and accessibility improvements supported by user evidence
- Other operating systems, architectures, and languages after their build, test, signing, and support paths are owned

## Outside KinPad's scope

- Accounts, cloud sync, collaboration, or hosted documents
- Advertising, telemetry, subscriptions, or document monetization
- AI writing features or plugins
- Rich publishing and long-form project management

Considering an item is not a commitment. KinPad has no fixed release schedule. Releases follow meaningful, validated changes; important security or stability fixes may ship sooner.
